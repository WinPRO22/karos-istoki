# Karos: Истоки — Бернео
**Русский** · [English](README.en.md) · [Español](README.es.md)

Эмулятор сервера для оригинального **Karos NHN EN CBT1 b1008 (14 августа 2009)**.
Автор: [WinPRO22](https://github.com/WinPRO22). [Новости проекта](https://t.me/karos_istoki).

Публичный снимок завершённого этапа: **одна карта — Бернео, развитие до 45-го уровня**.
Исходники и инструменты доступны для продолжения разработки. Это локальная
однопользовательская сборка; она не является готовым публичным MMO-сервером.

## Что входит
- Вход, создание персонажа, сохранение состояния.
- 955 существ, 29 NPC, 16 магазинов и 41 включённое задание Бернео.
- Автобой, агро, респавн, характеристики, экипировка, опыт, профессии и навыки.
- Инвентарь, добыча, торговля, склад, камень возвращения, Флетта, крафт и улучшения.
- Авторские патчи клиента: быстрые действия мышью, Enter в диалогах, обмен
  навыков на панели, сохранение её рядов, исправления баффов и боевых состояний.

Глубже всего проработаны мечник и его профессии. Наличие обработчика не означает
полную проверку всех комбинаций. Баланс содержит согласованные авторские формулы.
Другие карты, закрытые исследования и новый движок в этот выпуск не входят.

## Скачать и запустить
Скачайте **оба ZIP** со [страницы Releases](https://github.com/WinPRO22/karos-istoki/releases):
клиент b1008 и эмулятор Win64. Установка Delphi для готовой сборки не нужна.

1. Распакуйте эмулятор в доступную для записи папку, например `C:\Games\KarosIstoki`.
2. Распакуйте клиент туда же: должна появиться папка `client` с `AMo.exe`.
3. Откройте PowerShell в папке эмулятора и выполните:
   `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Berneo.ps1 -ClientDirectory .\client`
4. В игре используйте демонстрационные логин **test** и пароль **test**.
   Создайте нового героя. В архиве нет сохранения разработчика.
5. После выхода из игры завершите сервер:
   `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Stop-Berneo.ps1`

Сервер слушает только `127.0.0.1:10001`; не меняйте брандмауэр и не открывайте
этот порт в Интернет. По умолчанию все рейты и скорость — **×1**.
Не смешивайте этот клиент с обновлятором или ресурсами других билдов.

## Сборка и данные
Нужны Windows x64 и Delphi с Win64-компилятором, VCL, Indy и FireDAC.
Проверка выполняется на Delphi 37.0. Добавьте `dcc64.exe` в PATH.
Из корня репозитория: `.\ServerEmulator\Build.ps1`.
Скрипт собирает программы и публичные автономные тесты, не запускает игру.
Для сборки без тестов: `.\ServerEmulator\Build.ps1 -SkipTests`.

Игровые каталоги и баланс: `ServerEmulator/data/b1008`.
Сохранения создаются там как `test-character.b1008*`, база контента —
`ServerEmulator/data/karos-emulator.sqlite3`. Перед обновлением делайте резервную
копию данных при остановленном сервере; не заменяйте сохранения файлами релиза.

Инструкция для разработчиков и ИИ-агентов:
[SKILL.md](skills/karos-berneo-development/SKILL.md).
Публичные тесты не требуют приватных архивов и не заменяют игровой прогон.
Перед публикацией проводится отдельный ручной прогон релизного комплекта;
его результат указывается в описании выпуска.
